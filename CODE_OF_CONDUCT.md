# Code de conduite

## L'esprit

Ce projet touche a l'auto-hebergement, un domaine ou les gens arrivent avec des niveaux
tres differents. Quelqu'un qui ne sait pas ce qu'est un hardlink a autant sa place ici
que quelqu'un qui ecrit des connecteurs d'API.

## Ce qu'on attend

- Repondre a la question posee, pas a celle qu'on aurait prefere.
- Expliquer plutot que renvoyer vers « c'est dans la doc ».
- Critiquer le code, la decision, l'hypothese. Jamais la personne.
- Accepter qu'on puisse avoir tort, y compris quand on maintient le projet.

## Ce qui n'a pas sa place

Le harcelement, les attaques personnelles, les remarques sur l'identite, l'origine, le
genre, l'orientation, l'age, le handicap ou l'apparence. La publication d'informations
privees sans accord. Le mepris affiche envers les debutants.

## Sur les indexeurs et le contenu

`arrsenal` ne fournit, n'heberge et ne recommande aucun indexeur, aucun tracker, aucun
contenu. **Ce n'est pas un lieu ou en demander, en partager ou en recommander.** Les
messages qui le font seront fermes, sans debat. Ce n'est pas de la pudeur : c'est ce qui
protege le projet et ses utilisateurs. Voir [DISCLAIMER.md](DISCLAIMER.md).

## Signaler

Ecrivez aux mainteneurs a l'adresse indiquee dans le profil du depot, ou ouvrez une
issue si le sujet peut etre traite publiquement. Les signalements sont traites de facon
confidentielle.

Les mainteneurs peuvent editer, masquer ou supprimer les contributions qui ne respectent
pas ce document, et expliqueront leur decision quand c'est possible.
